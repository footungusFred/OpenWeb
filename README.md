# OpenWeb

**Build your corner of the web.**

OpenWeb is an experimental open web platform that allows users to create, publish, discover, and browse websites within a shared digital ecosystem.

The project combines Java, Python, and modern web technologies to build a complete web platform from the ground up.

## What OpenWeb aims to provide

* User accounts and profiles
* Website creation and editing
* HTML, CSS, and JavaScript support
* Website publishing
* Personal website addresses
* Website discovery and search
* Bookmarks
* Website analytics
* Custom browsing experience
* Developer APIs
* Secure website isolation
* Background processing and automation

## Technology

OpenWeb uses multiple technologies, each with a specific role:

* **Java** — core backend and API
* **Python** — search, analytics, automation, and background services
* **Web technologies** — frontend and website editor
* **PostgreSQL** — persistent data
* **Redis** — caching and background infrastructure

## Project Status

OpenWeb is an active project under development.

Development is organized into milestones, gradually expanding the platform from its core infrastructure into a complete web ecosystem.

## Goal

The goal of OpenWeb is to make creating and publishing a website accessible while providing the infrastructure needed to build a larger, interconnected web of user-created sites.
